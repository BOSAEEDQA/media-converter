# محوّل الوسائط — Media Converter Pro

برنامج لنظامي **macOS و Windows** بواجهة عربية احترافية داكنة، فيه أداتان:

| الأداة | المدخل | المخرج |
|---|---|---|
| **تحويل الفيديو** | **أي فيديو** (AVI · MP4 · MOV · MKV · WMV · FLV · MTS · WEBM …) | MP4 · MKV · MOV · WEBM · WMV · FLV · MPEG · 3GP · GIF — أو استخراج الصوت MP3 · M4A · WAV |
| **تحويل الصوت** | **أي صوت** (WAV · M4A · FLAC · AAC · OGG · AIFF · WMA · MP3 …) | **MP3** (128 / 192 / 256 / 320 kbps) |

## المميزات
- سحب وإفلات ملفات أو مجلدات كاملة، وتحويل عدة ملفات دفعة وحدة
- شريط تقدّم لكل ملف وتقدّم إجمالي، وزر إيقاف
- خيارات الجودة (عالية / متوازنة / حجم أصغر) والدقة (الأصلية / 1080p / 720p / 480p)
- لملفات الصوت: معدل البت، معدل العينة، القنوات، مع الحفاظ على البيانات وصورة الغلاف
- اختيار مجلد الحفظ أو الحفظ بجانب الملف الأصلي، وما يكتب فوق ملف موجود أبداً
- يحفظ آخر إعداداتك تلقائياً
- محرك FFmpeg مدمج — **اللي يستخدم البرنامج ما يحتاج يثبّت أي شي، ولا حتى بايثون**

## النسخ المتوفرة
| الملف | الجهاز |
|---|---|
| `MediaConverter-macOS.zip` | ماك — Intel و Apple Silicon (M1–M5) بدون Rosetta |
| `MediaConverter-Windows.zip` | ويندوز — نسخة مجلد (أسرع في الفتح) |
| `MediaConverter-Portable.exe` | ويندوز — **محمولة**: ملف واحد يشتغل من الفلاش، وإعداداتها تنحفظ بجانبها |

## البناء التلقائي على GitHub (بدون بايثون وبدون جهاز ويندوز)
الملف `.github/workflows/build.yml` يخلّي GitHub يبني النسخ الثلاث على أجهزته:
1. في صفحة المستودع: تبويب **Actions** ← **Build** ← **Run workflow**.
2. اكتب رقم الإصدار (مثل `v1.0`) ← **Run workflow**.
3. بعد ~10 دقائق تلقى النسخ الثلاث في **Releases** جاهزة للتحميل.
   (لو تركت الرقم فاضي: يبني بس، والملفات تنزل من صفحة التشغيل تحت **Artifacts**.)

> المستودع الخاص له 2000 دقيقة مجانية شهرياً. تشغيلة كاملة تستهلك تقريباً 100 دقيقة
> من الرصيد (دقائق الماك تنحسب ×10 والويندوز ×2)، فشغّلها عند كل إصدار مو مع كل تعديل.

## المشاركة مع أشخاص محددين فقط
- المستودع **Private** — ما يشوفه إلا أنت واللي تعزمهم.
- **Settings ← Collaborators ← Add people** (لازم يكون عندهم حساب GitHub).
- لو تبيهم **ينزّلون بس بدون تعديل**: انقل المستودع لـ Organization مجانية واعزمهم بصلاحية **Read**.

## أول تشغيل (البرنامج غير موقّع بشهادة مدفوعة)
- **ماك:** «Not Opened» ← **Done** ← إعدادات النظام ← الخصوصية والأمان ← **Open Anyway**.
- **ويندوز:** «Windows protected your PC» ← **More info** ← **Run anyway**.

## البناء على جهازك
- **ماك:** `./build_app.sh` ← `dist/محوّل الوسائط.app` + ملف zip
- **ويندوز:** اضغط مرتين على `build_windows.bat` — لو بايثون مو مثبّت، يعرض يثبّته لك تلقائياً
- **تشغيل من الكود للتجربة:** `.venv/bin/python app.py` (ماك) أو `.venv\Scripts\python.exe app.py` (ويندوز)
